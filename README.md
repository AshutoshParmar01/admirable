# Admirable

Admirable is a simple website builder like [Lovable](https://lovable.dev). Build modern React + TypeScript websites with a visual, prompt-driven workflow.

## Features

- Visual website building
- React, TypeScript, Tailwind CSS, and shadcn/ui components
- Vite for fast development and builds

## Getting started

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
